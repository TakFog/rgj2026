# Ideologia Marina — Implementation Roadmap

> **For agentic workers:** this is the index. Each phase/track below links to its own plan; execute those with superpowers:subagent-driven-development or superpowers:executing-plans.

**Goal:** Ship the MVP described in `docs/GDD.md`: a real-time reef-balance survival game in Godot 4.7, built by two developers in parallel without stepping on each other.

**Architecture:** Hidden top-down logical `World` (2D physics, 20×20 grid of 32-unit cells) and a y-sorted screen `View` that mirrors it through a parametric oblique projection (`/__/`). Static entities (corals, algae, nests) live on the grid; fish and threats move freely. Pure rules live in unit-tested `RefCounted` classes under `core/`; nodes are thin adapters. Everything is wired through the `Game` autoload.

**Tech Stack:** Godot 4.7.2, GDScript, Compatibility renderer, custom headless test runner (`tools/test.sh`), smoke test (`tools/smoke.sh`).

## Cross-track contracts (fixed here so the two tracks agree)

These extend the entity contract in P0 Task 8. Do not rename them.

1. **Temperature** — `Game.temperature` (0..1) is written only by A3. Everyone else reads it through `Game.by_temperature(cold, hot)`. Until A3 lands it stays `0.0`, so all "cold" values apply.
   - A1 algae growth interval: `Game.by_temperature(eco.algae_growth_interval_cold, eco.algae_growth_interval_hot)`.
   - B1 fish speed: `actors.fish_speed * Game.by_temperature(1.0, actors.fish_speed_hot_factor)`.
   - B3 spawn intervals: `Game.by_temperature(actors.co2_interval_cold, actors.co2_interval_hot)` and the same for cyclones.
2. **"Is a fish or threat over this cell?"** — A1 creates `core/cell_probe.gd` with `static func is_covered_by_actor(cell: Vector2i) -> bool` (physics `intersect_shape`, mask `Layers.FISH | Layers.THREAT`, bodies and areas). Used by algae spread (A1) and placement (A2).
3. **Algae ↔ CO2** — B3 calls `algae.on_co2_absorbed()` and then destroys the cloud. A1 implements it as "attempt one expansion immediately".
4. **Fish ↔ nest** — B1 finds the nest under a fish with a physics point query (`mask = Layers.NEST`, `collide_with_areas = true`), checks `nest.is_empty()` and `fish.is_adult()`, waits `actors.fertilize_seconds`, then calls `nest.fertilize()`. A2 implements `fertilize()` (start the hatch timer), `eggs_time_left()`, and hatching: `Game.factory.spawn_fish(Game.grid.cell_to_world(cell) + small offset, false)` × `eco.nest_hatch_count`.
5. **Nest ↔ CO2/cyclone** — B3 calls `nest.kill_eggs()` (CO2) and `nest.destroy()` (cyclone). A2 makes `kill_eggs()` cancel the hatch timer.
6. **Coral ↔ threats** — B3 calls `coral.apply_oxygen_damage(actors.co2_coral_damage)` once per cloud per coral, `apply_oxygen_damage(actors.bag_coral_damage)` for bags, `coral.destroy()` for cyclones. A1 owns regen and crumbling.
7. **Fish ↔ algae** — B1 detects "stopped against algae" from the `KinematicCollision2D` collider being in `Groups.ALGAE`, waits `actors.eat_seconds`, then calls `algae.destroy()` if still valid.
8. **Input** — A2's placement controller owns clicks while `Game.placing` is true: it handles `command`/`cancel` in `_unhandled_input` and calls `get_viewport().set_input_as_handled()`. B1's fish commander ignores `command` while `Game.placing`. B2's pause controller handles `pause` only when the event was not handled (Esc cancels placement first).
9. **Population counts** — B2 counts `get_tree().get_nodes_in_group(...)` for `Groups.CORALS`, `ALGAE`, `FISH`, `NESTS` (map only; inventory does not count). `destroy()` removes from the group immediately, so counts are exact.
10. **Fish-population rescue hint** — B2's collapse warning for fish reads the smallest positive `nest.eggs_time_left()` across `Groups.NESTS` (−1 means no eggs). Works with the P0 stub (shows nothing) until A2 lands.
11. **Restart** — B2's game-over "Restart" calls `get_tree().reload_current_scene()`. `Main._ready()` calls `Game.reset()`, so systems must not cache `Game.grid`/`Game.projection` across runs in static variables.
12. **UI placement** — A: inventory (bottom centre), thermometer (top right). B: population counters (top left), score/time (top centre), collapse warning (below score), threat edge warnings (screen edges), pause and game-over overlays (full screen). All UI goes under `Game.ui` (CanvasLayer, `PROCESS_MODE_ALWAYS`); UI nodes that must stop during pause set `process_mode = PROCESS_MODE_PAUSABLE`.
13. **Pausability** — gameplay systems and entities use the default (pausable) process mode and only advance timers with `delta`. Never use `Time.get_ticks_msec()` for gameplay.

## Checkpoints

**Checkpoint 1 (after A1 + B1 are on `main`)** — run together, 15 minutes:
- `tools/test.sh` and `tools/smoke.sh` green on `main`.
- Play: algae spread over time and damage adjacent corals; corals regenerate and crumble at 0 oxygen; fish wander, can be selected and ordered, stop at corals/algae, eat algae (algae disappear), starve after 60 s; an adult fish ordered onto the nest makes it turn to eggs (stub).
- Fix contract mismatches immediately in a small shared PR.

**Checkpoint 2 — first playable (after A2 + B2)**:
- Inventory refills, placement preview green/red, placing blocked over fish.
- Nest hatches 3 juvenile fish that mature in 45 s.
- Counters update; a population at 0 starts a 10 s countdown; recovering cancels it; expiry shows game over with the score; restart works; pause works and Esc cancels placement first.
- **Playtest for 10 minutes each and write down balance notes** in `docs/playtest-notes.md`.

**Checkpoint 3 — feature complete (after A3 + B3)**:
- Thermometer rises, slower with more coral cells; algae grow faster, fish slow down, threats spawn more often as it heats up.
- Each threat is announced 2.5 s before entering and follows every row of GDD §8.
