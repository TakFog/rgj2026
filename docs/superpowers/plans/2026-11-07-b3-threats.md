# B3 — Threats (CO2, Plastic Bag, Cyclone) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the external pressure of GDD M5: CO2 clouds, plastic bags and cyclones that are announced 2.5 s in advance at the map edge, drift across the reef and apply every row of the GDD §8 interaction table on contact.

**Architecture:** Four pure, unit-tested rule classes: `ThreatSchedule` (independent spawn timers, temperature-driven), `EdgeEntry` (entry point and inward heading on the world edge), `DriftMotion` (heading random walk) and `ThreatRules` (the GDD §8 table as data). These drive thin `Area2D` nodes (`Threat` base class plus `Co2Cloud`, `PlasticBag`, `Cyclone`) living in the logical `World`, and a `ThreatSpawner` system that shows a blinking edge warning in `Game.ui` before spawning. Every contact is instant: the threat reacts in `body_entered` / `area_entered` and calls only the frozen entity contract (P0 Task 8 + roadmap contracts #3, #5, #6).

**Tech Stack:** Godot 4.7.2, GDScript, headless test runner from P0 (`tools/test.sh`, `tools/smoke.sh`).

**Owner:** Dev B. **Depends on:** P0, B1, B2 merged on `main`. **Runs in parallel with:** A3 (temperature). Relies only on P0 and roadmap contracts, so it works the same with the P0 stubs or the A1/A2 versions of coral, algae and nest.

## Context for the engineer

- Read `docs/GDD.md` §6 (temperature effects), §7 (threats) and §8 (interaction table), and `docs/superpowers/plans/2026-11-07-00-roadmap.md` (ownership, contracts #1, #3, #5, #6, #12, #13).
- World units are logical (cell = 32 units, world = 640 × 640). Threats never use the grid. They are `Area2D`s that touch static bodies (corals, algae), character bodies (fish) and other areas (nests, other threats).
- **Contact = overlap of the threat circle with any collision shape of the target.** `body_entered` fires once per body (not per cell), so a multi-cell coral is "touched" once when the first of its cells is reached.
- **Physics callback rule:** inside `body_entered` / `area_entered` never toggle `monitoring` / `monitorable` or add collision objects directly. Use `set_deferred`. Entity `destroy()` methods already follow this rule (P0/A1). Calling `queue_free()` inside a callback is safe.
- **Double processing:** several contact signals can fire for one threat in the same physics step. `Threat._dead` makes every callback after death a no-op, and every target `destroy()` is idempotent (P0 contract).
- Temperature is `0.0` until A3 lands, so the cold intervals apply (CO2 every 30 s, cyclone every 90 s, bag every 40 s).
- `ThreatSchedule` is pure, so it lerps by temperature itself with the same clamped curve as `Game.by_temperature` (roadmap contract #1). The spawner passes `Game.temperature`.

> **Test runner caveat (same as P0/A1):** the runner keeps counting other tests when a test script fails to compile, so always check that the output has **no `SCRIPT ERROR` line**: `tools/test.sh 2>&1 | grep -c "SCRIPT ERROR"` must print `0`.

```gdscript
class_name ThreatSchedule
extends RefCounted
## Independent spawn timers per threat type (GDD §6, §7). Pure: no scene tree.
## Timers are progress-based (progress += delta / interval), so a temperature
## change also speeds up the countdown that is already running.

enum Type { CO2, BAG, CYCLONE }

var _actors: BalanceActors
var _progress := {Type.CO2: 0.0, Type.BAG: 0.0, Type.CYCLONE: 0.0}


func _init(actors: BalanceActors) -> void:
	_actors = actors


## Seconds between two threats of `kind` at `temperature` (clamped to 0..1).
## Same curve as Game.by_temperature (roadmap contract #1). Bags ignore temperature.
func interval(kind: Type, temperature: float) -> float:
	var t := clampf(temperature, 0.0, 1.0)
	match kind:
		Type.CO2:
			return lerpf(_actors.co2_interval_cold, _actors.co2_interval_hot, t)
		Type.CYCLONE:
			return lerpf(_actors.cyclone_interval_cold, _actors.cyclone_interval_hot, t)
	return _actors.bag_interval


## Advances every timer and returns the threat types that are due now.
## A type can appear more than once if `delta` spans several intervals.
func tick(delta: float, temperature: float) -> Array[int]:
	var due: Array[int] = []
	for kind in _progress.keys():
		_progress[kind] += delta / interval(kind, temperature)
		while _progress[kind] >= 1.0:
			_progress[kind] -= 1.0
			due.append(kind)
	return due
```

```gdscript
class_name EdgeEntry
extends RefCounted
## Where a threat enters the map (GDD §7): a random point on one of the four
## world edges and a heading pointing inward, randomised within ±spread radians.

var point: Vector2
## Unit vector perpendicular to the chosen edge, pointing into the world.
var inward: Vector2
var heading: float


static func random(rng: RandomNumberGenerator, world_size: Vector2, spread: float) -> EdgeEntry:
	var entry := EdgeEntry.new()
	match rng.randi_range(0, 3):
		0: # top
			entry.point = Vector2(rng.randf_range(0.0, world_size.x), 0.0)
			entry.inward = Vector2.DOWN
		1: # bottom
			entry.point = Vector2(rng.randf_range(0.0, world_size.x), world_size.y)
			entry.inward = Vector2.UP
		2: # left
			entry.point = Vector2(0.0, rng.randf_range(0.0, world_size.y))
			entry.inward = Vector2.RIGHT
		_: # right
			entry.point = Vector2(world_size.x, rng.randf_range(0.0, world_size.y))
			entry.inward = Vector2.LEFT
	entry.heading = entry.inward.angle() + rng.randf_range(-spread, spread)
	return entry
```

```gdscript
class_name DriftMotion
extends RefCounted
## Smooth random heading for drifting threats (GDD §7: "almost straight with
## random curves" for CO2, "more random" for bags, straight for cyclones).
## The turn rate random-walks within ±turn_noise rad/s.

## How fast the turn rate itself changes, relative to turn_noise.
const RATE_CHANGE := 3.0

var turn_noise: float
var _rng: RandomNumberGenerator
var _turn_rate := 0.0


func _init(p_turn_noise: float, rng: RandomNumberGenerator) -> void:
	turn_noise = p_turn_noise
	_rng = rng


## Returns the heading after `delta` seconds. Never turns more than turn_noise * delta.
func step(heading: float, delta: float) -> float:
	if turn_noise <= 0.0:
		return heading
	var change := _rng.randf_range(-1.0, 1.0) * turn_noise * RATE_CHANGE * delta
	_turn_rate = clampf(_turn_rate + change, -turn_noise, turn_noise)
	return heading + _turn_rate * delta
```

```gdscript
class_name ThreatRules
extends RefCounted
## GDD §8 interaction table for threats, as pure data. Every damage is instant
## on contact. Combinations not listed here do nothing.

enum Target { NONE, CORAL, ALGAE, FISH, NEST, THREAT }
enum Effect { NOTHING, DAMAGE_CORAL, DESTROY, ABSORB_CO2, KILL_EGGS }


## What happens to the touched target, and whether the threat disappears.
class Outcome:
	var effect: int
	var amount: float
	var threat_dies: bool

	func _init(p_effect: int, p_amount: float, p_threat_dies: bool) -> void:
		effect = p_effect
		amount = p_amount
		threat_dies = p_threat_dies


## `already_hit` is true when this threat already touched this target before
## (only used for "CO2 damages each coral once"). `nest_has_eggs` only matters for NEST.
static func resolve(kind: int, target: int, actors: BalanceActors, already_hit: bool, nest_has_eggs: bool) -> Outcome:
	match kind:
		ThreatSchedule.Type.CO2:
			match target:
				Target.CORAL:
					if not already_hit:
						return Outcome.new(Effect.DAMAGE_CORAL, actors.co2_coral_damage, false)
				Target.ALGAE:
					return Outcome.new(Effect.ABSORB_CO2, 0.0, true)
				Target.NEST:
					if nest_has_eggs:
						return Outcome.new(Effect.KILL_EGGS, 0.0, false)
		ThreatSchedule.Type.BAG:
			match target:
				Target.FISH:
					return Outcome.new(Effect.DESTROY, 0.0, false)
				Target.CORAL:
					return Outcome.new(Effect.DAMAGE_CORAL, actors.bag_coral_damage, true)
		ThreatSchedule.Type.CYCLONE:
			match target:
				Target.CORAL:
					return Outcome.new(Effect.DESTROY, 0.0, true)
				Target.FISH, Target.ALGAE, Target.NEST, Target.THREAT:
					return Outcome.new(Effect.DESTROY, 0.0, false)
	return Outcome.new(Effect.NOTHING, 0.0, false)


## Classifies a touched node by its group (P0 contract: every entity is in one group).
static func target_of(node: Node) -> int:
	if node.is_in_group(Groups.CORALS):
		return Target.CORAL
	if node.is_in_group(Groups.ALGAE):
		return Target.ALGAE
	if node.is_in_group(Groups.FISH):
		return Target.FISH
	if node.is_in_group(Groups.NESTS):
		return Target.NEST
	if node.is_in_group(Groups.THREATS):
		return Target.THREAT
	return Target.NONE
```

```gdscript
const EXIT_MARGIN := 32.0
## Screen pixels the threat body floats above its ground shadow.
const HOVER_PX := 18.0

var kind: int = ThreatSchedule.Type.CO2
var radius := 16.0
var speed := 40.0
var turn_noise := 0.0
var color := Color.WHITE
var heading := 0.0

var _drift: DriftMotion
var _hit := {} # target instance id -> true
var _dead := false


## Places the threat just outside the map at `entry`, heading inward.
## Call before adding the node to the tree.
func setup(entry: EdgeEntry, rng: RandomNumberGenerator) -> void:
	heading = entry.heading
	position = entry.point - Vector2.from_angle(heading) * radius
	_drift = DriftMotion.new(turn_noise, rng)


func _ready() -> void:
	collision_layer = Layers.THREAT
	collision_mask = Layers.CORAL | Layers.ALGAE | Layers.FISH | Layers.NEST | Layers.THREAT
	monitoring = true
	monitorable = true
	add_to_group(Groups.THREATS)
	var circle := CircleShape2D.new()
	circle.radius = radius
	var shape := CollisionShape2D.new()
	shape.shape = circle
	add_child(shape)
	body_entered.connect(_on_contact)
	area_entered.connect(_on_contact)
	ViewFollower.attach(self, _make_visual())


func _physics_process(delta: float) -> void:
	if _dead:
		return
	if _drift:
		heading = _drift.step(heading, delta)
	position += Vector2.from_angle(heading) * speed * delta
	var alive_area := Rect2(Vector2.ZERO, Game.grid.world_size()).grow(radius * 2.0 + EXIT_MARGIN)
	if not alive_area.has_point(position):
		destroy()


## Instant contact resolution. Safe to call several times in one physics step.
func _on_contact(other: Node2D) -> void:
	if _dead or not is_instance_valid(other) or other.is_queued_for_deletion():
		return
	var target := ThreatRules.target_of(other)
	if target == ThreatRules.Target.NONE:
		return
	var key := other.get_instance_id()
	var nest_has_eggs := target == ThreatRules.Target.NEST and (other as Nest).has_eggs()
	var outcome := ThreatRules.resolve(kind, target, Game.actors, _hit.has(key), nest_has_eggs)
	_hit[key] = true
	match outcome.effect:
		ThreatRules.Effect.DAMAGE_CORAL:
			(other as Coral).apply_oxygen_damage(outcome.amount)
		ThreatRules.Effect.DESTROY:
			other.call(&"destroy")
		ThreatRules.Effect.ABSORB_CO2:
			(other as Algae).on_co2_absorbed()
		ThreatRules.Effect.KILL_EGGS:
			(other as Nest).kill_eggs()
	if outcome.threat_dies:
		destroy()


## Ground shadow (the real contact footprint) plus a body floating above it.
func _make_visual() -> Node2D:
	var root := Node2D.new()
	root.add_child(PlaceholderShape.circle(position, radius, Color(0, 0, 0, 0.3)))
	var body := PlaceholderShape.circle(position, radius * 0.8, color)
	body.position = Vector2(0, -HOVER_PX)
	root.add_child(body)
	return root


## Idempotent. Safe inside physics callbacks (monitoring is toggled deferred).
func destroy() -> void:
	if _dead:
		return
	_dead = true
	remove_from_group(Groups.THREATS)
	set_deferred("monitoring", false)
	set_deferred("monitorable", false)
	destroyed.emit()
	queue_free()
```

The warning lives in `Game.ui` (screen space). It converts the world entry point through the projection and the View's canvas transform (which includes the camera), then clamps itself inside the viewport. It is pausable (roadmap contract #12).

```gdscript
extends Node2D
## Blinking arrow + label at the map edge announcing an incoming threat (GDD §7).

const MARGIN := 24.0
const BLINK_PERIOD := 0.4
const LABELS := {
	ThreatSchedule.Type.CO2: "CO2",
	ThreatSchedule.Type.BAG: "BAG",
	ThreatSchedule.Type.CYCLONE: "CYCLONE",
}
const COLORS := {
	ThreatSchedule.Type.CO2: Color(0.75, 0.75, 0.8),
	ThreatSchedule.Type.BAG: Color(1.0, 1.0, 1.0),
	ThreatSchedule.Type.CYCLONE: Color(0.45, 0.85, 0.95),
}

var kind: int
var _entry: EdgeEntry
var _time := 0.0
var _angle := 0.0


func setup(p_kind: int, entry: EdgeEntry) -> void:
	kind = p_kind
	_entry = entry


func _ready() -> void:
	process_mode = Node.PROCESS_MODE_PAUSABLE
	_update_placement()


func _process(delta: float) -> void:
	_time += delta
	visible = fmod(_time, BLINK_PERIOD) < BLINK_PERIOD * 0.6
	_update_placement()


func _update_placement() -> void:
	var canvas := Game.view.get_global_transform_with_canvas()
	var at := canvas * Game.projection.to_screen(_entry.point)
	var ahead := canvas * Game.projection.to_screen(_entry.point + Vector2.from_angle(_entry.heading) * 32.0)
	var screen := get_viewport_rect().grow(-MARGIN)
	position = at.clamp(screen.position, screen.end)
	_angle = (ahead - at).angle()
	queue_redraw()


func _draw() -> void:
	var dir := Vector2.from_angle(_angle)
	var side := dir.orthogonal()
	var arrow := PackedVector2Array([dir * 18.0, -dir * 10.0 + side * 12.0, -dir * 10.0 - side * 12.0])
	draw_colored_polygon(arrow, COLORS[kind])
	draw_string(ThemeDB.fallback_font, Vector2(-20, -20), LABELS[kind], HORIZONTAL_ALIGNMENT_LEFT, -1, 14, COLORS[kind])
```

- [ ] **Step 2: Create `systems/b_threat_spawner.gd`**

`spawn()` is the threat track's own spawn helper (the frozen `EntityFactory` is not touched).

```gdscript
extends Node
## Announces threats at the map edge and spawns them after
## threat_warning_seconds (GDD §7). Pausable; timers advance with delta only.

const ThreatWarning := preload("res://ui/b_threat_warning.gd")
## ±30° around the inward direction.
const ENTRY_SPREAD := 0.5236


class Pending:
	var kind: int
	var entry: EdgeEntry
	var time_left: float
	var warning: Node


var _schedule: ThreatSchedule
var _rng := RandomNumberGenerator.new()
var _pending: Array[Pending] = []


func _ready() -> void:
	_rng.randomize()
	_schedule = ThreatSchedule.new(Game.actors)


func _process(delta: float) -> void:
	for kind in _schedule.tick(delta, Game.temperature):
		_announce(kind)
	for i in range(_pending.size() - 1, -1, -1):
		var pending := _pending[i]
		pending.time_left -= delta
		if pending.time_left <= 0.0:
			_pending.remove_at(i)
			if is_instance_valid(pending.warning):
				pending.warning.queue_free()
			spawn(pending.kind, pending.entry, _rng)


func _announce(kind: int) -> void:
	var pending := Pending.new()
	pending.kind = kind
	pending.entry = EdgeEntry.random(_rng, Game.grid.world_size(), ENTRY_SPREAD)
	pending.time_left = Game.actors.threat_warning_seconds
	var warning := ThreatWarning.new()
	warning.setup(kind, pending.entry)
	Game.ui.add_child(warning)
	pending.warning = warning
	_pending.append(pending)


## Creates a threat of `kind` entering at `entry` and adds it to the world.
static func spawn(kind: int, entry: EdgeEntry, rng: RandomNumberGenerator) -> Threat:
	var threat: Threat
	match kind:
		ThreatSchedule.Type.CO2:
			threat = Co2Cloud.new()
		ThreatSchedule.Type.BAG:
			threat = PlasticBag.new()
		_:
			threat = Cyclone.new()
	threat.setup(entry, rng)
	Game.world.add_child(threat)
	return threat
```
