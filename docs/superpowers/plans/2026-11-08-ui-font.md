# UI Font Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Render every string in BalanSea with Archivo at weight 900 (the free Britannic Bold lookalike) through one project-wide theme.

**Architecture:** One `Theme` resource, `res://ui/ui_theme.tres`, carries a `FontVariation` (Archivo variable, `wght 900`) as `default_font`; `gui/theme/custom` makes it the project theme so every `Control` inherits it. The one custom-drawn string outside a `Control` (the fish hunger warning) resolves the same theme font.

**Tech Stack:** Godot 4.7.2 stable, GDScript, Compatibility renderer, web export via CD.

**Spec:** `docs/superpowers/specs/2026-11-08-ui-font-design.md`

## Global Constraints

- Godot 4.7.2 stable; web export stays single-threaded.
- `tools/lint.sh` and `tools/test.sh` must report zero errors and zero GDScript warnings.
- Never work on `main`; work stays on `TakFog/britannic-font` (already branched from `origin/main`).
- Commit messages in English. Stage files by explicit path; never `git add -A` / `git add .`.
- **Never stage `project.godot` wholesale**: the working copy has unrelated local `[editor]` and audio-latency changes. Stage only the `[gui]` addition, with the blob recipe in Task 1.
- Font: Google Fonts Archivo variable, SIL OFL, shipped in `assets/fonts/` with its `OFL.txt`.
- Do not set `default_font_size`: the theme must inherit the engine's 16 px exactly as today.

## Review Focus

- Theme or font path missing → every screen silently falls back to Open Sans. Pinned by `test_project_theme_uses_archivo` (Task 1).
- Weight axis not applied (or set under the silently ignored `"wght"` string key) → labels render in Archivo's default SemiBold 600 instead of Black 900. Pinned by the OpenType-tag and glyph-width assertions (Task 1).
- A glyph the UI prints is absent from the font → tofu. Pinned by `test_theme_font_has_every_ui_glyph` (`₂ → − ° è é Ì · —`, Task 1).
- A `Control` created later or in an isolated scene not inheriting the theme → mixed typefaces. Pinned by `test_label_inherits_project_font` (Task 1).
- Custom-drawn entity text bypassing the theme (fish hunger warning) → mixed typeface. Pinned by `test_fish_warning_uses_project_font` (Task 2).

- [ ] **Step 1: Write the failing test**

Create `tests/unit/test_ui_theme.gd`:

```gdscript
extends TestCase
## Guards the project-wide typeface: all text uses Archivo, the free
## stand-in for Britannic Bold, resolved through the project theme.

const THEME_PATH := "res://ui/ui_theme.tres"
## Symbols the UI actually prints: è é Ì ° ₂ · − — →
const UI_CODEPOINTS: Array[int] = [0x00E8, 0x00E9, 0x00CC, 0x00B0, 0x2082, 0x00B7, 0x2212, 0x2014, 0x2192]


func test_project_theme_uses_archivo() -> void:
	assert_eq(ProjectSettings.get_setting("gui/theme/custom"), THEME_PATH)
	var theme := load(THEME_PATH) as Theme
	assert_true(theme != null, "ui_theme.tres must load")
	if theme == null:
		return
	var variation := theme.default_font as FontVariation
	assert_true(variation != null, "default_font must be a FontVariation")
	if variation == null:
		return
	assert_true(variation.base_font.get_font_name().contains("Archivo"))
	var tag := TextServerManager.get_primary_interface().name_to_tag("wght")
	assert_eq(int(variation.variation_opentype.get(tag, 0)), 900,
			"wght must be set under its OpenType tag, not the 'wght' text")
	# A key the engine ignores leaves the width at the font's default instance
	# (SemiBold 600), so compare the active axis against the base font directly.
	assert_true(variation.get_char_size(0x2082, 16).x > variation.base_font.get_char_size(0x2082, 16).x,
			"wght 900 must render wider than the font's default instance")


func test_theme_font_has_every_ui_glyph() -> void:
	var theme := load(THEME_PATH) as Theme
	if theme == null or theme.default_font == null:
		assert_true(false, "theme font missing")
		return
	for codepoint in UI_CODEPOINTS:
		assert_true(theme.default_font.has_char(codepoint),
				"Archivo must contain U+%04X" % codepoint)


func test_label_inherits_project_font() -> void:
	var tree := Engine.get_main_loop() as SceneTree
	var label := Label.new()
	label.text = "CO₂"
	tree.root.add_child(label)
	autofree(label)
	var theme := load(THEME_PATH) as Theme
	assert_true(theme != null)
	if theme == null:
		return
	assert_eq(label.get_theme_default_font(), theme.default_font)
```

- [ ] **Step 4: Create the theme resource**

Create `ui/ui_theme.tres`:

```ini
[gd_resource type="Theme" load_steps=3 format=3]

[ext_resource type="FontFile" path="res://assets/fonts/Archivo-Variable.ttf" id="1"]

[sub_resource type="FontVariation" id="FontVariation_archivo"]
base_font = ExtResource("1")
variation_opentype = {
2003265652: 900
}

[resource]
default_font = SubResource("FontVariation_archivo")
```

The key is the numeric OpenType tag `2003265652` (hex `0x77676874`, the `wght` axis).
Godot 4.7 looks variants up by the axis **name** returned by
`TextServer.tag_to_name()` (`"weight"`), so the string key `"wght"` is silently
ignored and leaves the font at its default SemiBold 600 — the width assertion in
the test catches that.

## The project UI font, so the warning glyph matches every label and button.
static func warning_font() -> Font:

	if theme != null and theme.default_font != null:
