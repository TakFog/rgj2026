# P4 — Polish (Art, Readability, Debug Overlay, Audio, Balance, Web Export) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the feature-complete build into a jam submission. Real art drops in without code changes, fish and nests stay readable behind corals, an F3 debug overlay supports balancing, sound effects play, the numbers get tuned through playtests, and a Web build is ready for itch.io (GDD §4.1, §9, M7).

**Architecture:** Art is opt-in per entity kind. `ArtLibrary` loads `res://art/<kind>.png` if it exists. `PlaceholderShape` draws that texture, anchored at its bottom centre (the "base" convention from GDD §4.1), instead of the flat polygon, so every existing `.color` tint keeps working as a modulate. Silhouettes are outline-only `PlaceholderShape`s with a high `z_index`, so they draw above the y-sorted corals. The debug overlay and audio are Dev B nodes that only read groups, signals and the public APIs from B1/B2.

**Tech Stack:** Godot 4.7.2, GDScript, Compatibility renderer, Web export templates.

**Owner:** split per task (marked **[A]**, **[B]**, **[shared]**). **Depends on:** Checkpoint 3 (A1–A3 and B1–B3 merged).

**Order:** Task 1 is a small shared PR and must be merged first. After that, Tasks 2–6 can run in parallel on separate branches, A and B. Tasks 7–8 are done together at the end.

```gdscript
class_name ArtLibrary
extends RefCounted
## Optional art per entity kind (GDD §4.1). Drop `res://art/<kind>.png` into the
## project and the matching entity uses it; otherwise the placeholder stays.
## Kinds: coral_cell, algae, nest_empty, nest_eggs, fish, co2, bag, cyclone.

const ART_DIR := "res://art"
## Optional per-kind vertical correction in screen pixels (positive = image moves
## down), for images whose "touches the seabed" point is not the bottom edge.
const ANCHOR_LIFT := {
	&"coral_cell": 0.0,
	&"algae": 0.0,
	&"nest_empty": 0.0,
	&"nest_eggs": 0.0,
	&"fish": 0.0,
	&"co2": 0.0,
	&"bag": 0.0,
	&"cyclone": 0.0,
}


## The texture for `kind`, or null when no art exists yet.
static func texture(kind: StringName) -> Texture2D:
	var path := "%s/%s.png" % [ART_DIR, kind]
	if ResourceLoader.exists(path):
		return load(path) as Texture2D
	return null


## Rect for drawing an image of `size` so its bottom centre sits on the origin.
static func anchor_rect(size: Vector2, lift: float) -> Rect2:
	return Rect2(Vector2(-size.x * 0.5, -size.y + lift), size)


## Gives `shape` the art for `kind` if it exists. With art the tint resets to
## white (untinted); entities that tint dynamically override `color` afterwards.
static func apply(shape: PlaceholderShape, kind: StringName) -> PlaceholderShape:
	var tex := texture(kind)
	if tex != null:
		shape.texture = tex
		shape.anchor_lift = ANCHOR_LIFT.get(kind, 0.0)
		shape.color = Color.WHITE
	return shape
```

- [ ] **Step 5: Replace `entities/placeholder_shape.gd`** (the existing helpers are unchanged; this adds `texture`, `anchor_lift`, `outline` and the drawing branches)

```gdscript
class_name PlaceholderShape
extends Node2D
## Flat-colour placeholder visual drawn in screen space, or real art when
## `texture` is set (see ArtLibrary). Build with the static helpers so world
## shapes are projected correctly.

var polygon := PackedVector2Array()
var color := Color.WHITE:
	set(value):
		color = value
		queue_redraw()
## Optional art: drawn instead of the polygon, bottom centre on the origin, tinted by `color`.
var texture: Texture2D:
	set(value):
		texture = value
		queue_redraw()
var anchor_lift := 0.0
## Draw only the outline of the polygon (used for see-through silhouettes).
var outline := false:
	set(value):
		outline = value
		queue_redraw()


## A full grid cell centred on `center_world`.
static func cell(center_world: Vector2, p_color: Color) -> PlaceholderShape:
	var half := Game.grid.cell_size * 0.5
	var corners := PackedVector2Array([
		center_world + Vector2(-half, -half), center_world + Vector2(half, -half),
		center_world + Vector2(half, half), center_world + Vector2(-half, half)])
	return _make(Game.projection.project_polygon(corners, center_world), p_color)


## A circle of `radius` world units centred on `center_world` (an ellipse on screen).
static func circle(center_world: Vector2, radius: float, p_color: Color) -> PlaceholderShape:
	var points := PackedVector2Array()
	for i in 16:
		points.append(center_world + Vector2.from_angle(TAU * i / 16.0) * radius)
	return _make(Game.projection.project_polygon(points, center_world), p_color)


static func _make(p_polygon: PackedVector2Array, p_color: Color) -> PlaceholderShape:
	var shape := PlaceholderShape.new()
	shape.polygon = p_polygon
	shape.color = p_color
	return shape


func _draw() -> void:
	if texture != null:
		draw_texture_rect(texture, ArtLibrary.anchor_rect(texture.get_size(), anchor_lift), false, color)
		return
	if polygon.is_empty():
		return
	if outline:
		var closed := polygon.duplicate()
		closed.append(polygon[0])
		draw_polyline(closed, color, 2.0)
	else:
		draw_colored_polygon(polygon, color)
```

- [ ] **Step 6: Create `art/README.md`**

```markdown
# Art drop-in folder

Put PNGs here named after the entity kind. The game uses them automatically.
Missing files fall back to the flat placeholder shapes.

| File | Used by |
|---|---|
| `coral_cell.png` | one coral cell (corals are drawn cell by cell) |
| `algae.png` | one algae cell |
| `nest_empty.png`, `nest_eggs.png` | nest without / with eggs |
| `fish.png` | fish (juveniles are drawn at 60 % scale) |
| `co2.png`, `bag.png`, `cyclone.png` | threat bodies (their ground shadow stays a placeholder) |

## Convention (GDD §4.1)
- The view is an oblique projection `/__/`: one cell is a parallelogram
  (`data/view_settings.tres`: x axis (1, 0), y axis (-0.5, 0.5), 1.25 px per unit,
  so a 32-unit cell is 40 px wide and 20 px deep, slanted 45°).
- **Anchor = bottom centre of the image** = the point where the object touches the
  seabed, which the game puts at the centre of the cell (or of the fish/threat).
  Tall things (corals) grow upwards from there.
- If the contact point is not the bottom edge, set its lift in pixels in
  `ArtLibrary.ANCHOR_LIFT` instead of padding the image.
- Draw in neutral/white-ish tones where the game tints the sprite: corals are
  tinted from grey-blue (suffocated) to white (healthy).
```

```gdscript
extends Label
## F3 debug overlay (GDD §9): live balance numbers and fish states.
## Read-only: it only inspects groups, Game and the public FishBrain API.

const REFRESH_SECONDS := 0.25

var _elapsed := 0.0


## "WANDER 2, EATING 1" from state ids and their enum names (in enum order).
static func state_histogram(states: Array, names: Array) -> String:
	var counts := {}
	for state in states:
		counts[state] = counts.get(state, 0) + 1
	var parts: Array[String] = []
	for id in names.size():
		if counts.has(id):
			parts.append("%s %d" % [names[id], counts[id]])
	return ", ".join(parts) if not parts.is_empty() else "-"


func _ready() -> void:
	process_mode = Node.PROCESS_MODE_ALWAYS
	visible = false
	position = Vector2(12, 140)
	add_theme_color_override(&"font_color", Color(1, 1, 0.6))
	add_theme_color_override(&"font_outline_color", Color.BLACK)
	add_theme_constant_override(&"outline_size", 4)


func _unhandled_input(event: InputEvent) -> void:
	if event.is_action_pressed(InputActions.DEBUG_OVERLAY):
		visible = not visible
		get_viewport().set_input_as_handled()


func _process(delta: float) -> void:
	if not visible:
		return
	_elapsed += delta
	if _elapsed < REFRESH_SECONDS:
		return
	_elapsed = 0.0
	text = _build_text()


func _build_text() -> String:
	var tree := get_tree()
	var states: Array = []
	var hungry := 0
	for node in tree.get_nodes_in_group(Groups.FISH):
		var fish := node as Fish
		if fish == null or fish.brain == null:
			continue
		states.append(fish.brain.state)
		if fish.brain.hunger_ratio() > Game.actors.hunger_bar_threshold:
			hungry += 1
	var coral_cells := Game.grid.count_cells(func(e): return e is Coral)
	var lines: Array[String] = [
		"FPS %d" % Engine.get_frames_per_second(),
		"Temperature %.3f  (algae interval %.1f s, fish speed x%.2f)" % [
			Game.temperature,
			Game.by_temperature(Game.eco.algae_growth_interval_cold, Game.eco.algae_growth_interval_hot),
			Game.by_temperature(1.0, Game.actors.fish_speed_hot_factor)],
		"Corals %d (%d cells)  Algae %d/%d  Nests %d  Threats %d" % [
			tree.get_nodes_in_group(Groups.CORALS).size(), coral_cells,
			tree.get_nodes_in_group(Groups.ALGAE).size(), Game.eco.algae_max_count,
			tree.get_nodes_in_group(Groups.NESTS).size(),
			tree.get_nodes_in_group(Groups.THREATS).size()],
		"Fish %d  hungry %d  states: %s" % [states.size(), hungry, state_histogram(states, FishBrain.State.keys())],
		"Placing %s  Paused %s" % [Game.placing, tree.paused],
	]
	return "\n".join(lines)
```

```gdscript
extends Node
## Plays drop-in sound effects for gameplay events. Missing files are silent.
## Files: res://audio/<event>.ogg with event in EVENTS.

const AUDIO_DIR := "res://audio"
const EVENTS: Array[StringName] = [&"coral_crumble", &"algae_gone", &"fish_death", &"fish_born", &"game_over"]
const VOICES := 6

var monitor: PopulationMonitor

var _streams := {} # StringName -> AudioStream
var _players: Array[AudioStreamPlayer] = []
var _next := 0


func _ready() -> void:
	process_mode = Node.PROCESS_MODE_ALWAYS
	for event in EVENTS:
		var path := "%s/%s.ogg" % [AUDIO_DIR, event]
		if ResourceLoader.exists(path):
			_streams[event] = load(path)
	for i in VOICES:
		var player := AudioStreamPlayer.new()
		add_child(player)
		_players.append(player)
	Game.world.child_entered_tree.connect(_on_entity_added)
	if monitor != null:
		monitor.game_over.connect(func(_population, _score): play(&"game_over"))


func play(event: StringName) -> void:
	if not _streams.has(event):
		return
	var player := _players[_next]
	_next = (_next + 1) % _players.size()
	player.stream = _streams[event]
	player.play()


func _on_entity_added(node: Node) -> void:
	if node is Coral:
		node.destroyed.connect(play.bind(&"coral_crumble"))
	elif node is Algae:
		node.destroyed.connect(play.bind(&"algae_gone"))
	elif node is Fish:
		node.destroyed.connect(play.bind(&"fish_death"))
		if not (node as Fish).is_adult():
			play(&"fish_born")
```

Note: `Game.world.child_entered_tree` only sees entities added **after** the audio node is ready. That is intended, because the starting Level01 entities should not trigger sounds.
