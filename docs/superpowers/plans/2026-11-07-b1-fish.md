# B1 — Fish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring the fish to life (GDD M2 + the fish half of M3): fish wander on their own, the player selects one and sends it straight to a point, it stops at the first obstacle, eats algae it was sent against, fertilizes an empty nest it was sent onto, grows up from juvenile to adult and starves if never fed.

**Architecture:** Two pure, unit-tested rule classes: `FishBrain` (state machine `WANDER / ORDERED / EATING / FERTILIZING / IDLE`, hunger, maturity, timers) and `WanderSteering` (random heading for a random time, turns away from walls). The `Fish` node (P0 contract kept) only moves with `move_and_collide`, turns collisions and nest queries into brain sensor events, and executes the brain's decisions (destroy the eaten algae, call `nest.fertilize()`). `FishVisual` draws the placeholder body, selection ring and hunger bar in screen space. `FishCommander` turns clicks into select/order commands. Randomness is injected so tests are deterministic.

**Tech Stack:** Godot 4.7.2, GDScript, headless test runner from P0 (`tools/test.sh`, `tools/smoke.sh`).

**Owner:** Dev B. **Depends on:** P0 merged on `main`. **Runs in parallel with:** A1 (coral & algae).

```gdscript
class_name WanderSteering
extends RefCounted
## Random wandering for fish (GDD §5.4): keep a random heading for a random
## time, then pick another; when blocked, turn away from the obstacle.

## Max deviation from the obstacle normal when bouncing (just under 90°).
const BOUNCE_SPREAD := PI * 0.45

var heading := Vector2.RIGHT

var _rng: RandomNumberGenerator
var _min_seconds: float
var _max_seconds: float
var _time_left := 0.0


func _init(rng: RandomNumberGenerator, min_seconds: float, max_seconds: float) -> void:
	_rng = rng
	_min_seconds = min_seconds
	_max_seconds = max_seconds
	_pick(Vector2.from_angle(_rng.randf_range(0.0, TAU)))


## Advances the timer and returns the heading to swim along this frame.
func tick(delta: float) -> Vector2:
	_time_left -= delta
	if _time_left <= 0.0:
		_pick(Vector2.from_angle(_rng.randf_range(0.0, TAU)))
	return heading


## Called when the fish bumps into something; `normal` points away from it.
func on_blocked(normal: Vector2) -> void:
	if normal == Vector2.ZERO:
		_pick(Vector2.from_angle(_rng.randf_range(0.0, TAU)))
		return
	_pick(normal.normalized().rotated(_rng.randf_range(-BOUNCE_SPREAD, BOUNCE_SPREAD)))


func _pick(new_heading: Vector2) -> void:
	heading = new_heading
	_time_left = _rng.randf_range(_min_seconds, _max_seconds)
```

### Task 3: FishBrain rules

**Files:**
- Create: `core/fish_brain.gd`
- Test: `tests/unit/test_fish_brain.gd`

Rules encoded here (GDD §5.4):
- `WANDER`: swims randomly, ignores algae and nests.
- `order(destination)` → `ORDERED` from any state (cancels eating/fertilizing; "leaving early" means no fertilization).
- While `ORDERED`: `blocked_by_algae(algae)` → `EATING`; `blocked_by_other()` → `IDLE`; `arrived(empty_nest)` → `FERTILIZING` if adult and a nest is given, otherwise `IDLE`.
- `EATING` lasts `eat_seconds`, then hunger resets to 0, `eat_finished(algae)` is emitted, back to `WANDER`. `food_lost()` (algae vanished) → `WANDER` without feeding.
- `FERTILIZING` lasts `fertilize_seconds`, then `fertilize_finished(nest)` is emitted, back to `WANDER`. `nest_lost()` → `WANDER`.
- `IDLE` lasts `idle_after_order_seconds`, then `WANDER`.
- Hunger grows every tick; at `starve_seconds` the fish is `dead` and `starved` is emitted once.
- A juvenile becomes adult after `maturity_seconds` and `matured` is emitted once.

```gdscript
class_name FishBrain
extends RefCounted
## Pure fish rules (GDD §5.4): state machine, hunger, maturity.
## The Fish node feeds it sensor events and executes its decisions.

signal starved
signal matured
signal eat_finished(algae: Object)
signal fertilize_finished(nest: Object)

enum State { WANDER, ORDERED, EATING, FERTILIZING, IDLE }

var state := State.WANDER
## Order destination in world units (meaningful while ORDERED).
var target := Vector2.ZERO
## Seconds since the last meal.
var hunger := 0.0
## Seconds lived as a juvenile (stops counting once adult).
var age := 0.0
var adult: bool
var dead := false
## Algae being eaten while EATING, otherwise null.
var food: Object = null
## Nest being fertilized while FERTILIZING, otherwise null.
var nest: Object = null

var _cfg: BalanceActors
var _timer := 0.0


func _init(cfg: BalanceActors, p_adult: bool) -> void:
	_cfg = cfg
	adult = p_adult


func is_adult() -> bool:
	return adult


func hunger_ratio() -> float:
	return clampf(hunger / _cfg.starve_seconds, 0.0, 1.0)


## True when the node should move this frame (wandering or following an order).
func wants_to_move() -> bool:
	return not dead and (state == State.WANDER or state == State.ORDERED)


## Player order: swim straight to `destination`. Cancels eating/fertilizing.
func order(destination: Vector2) -> void:
	if dead:
		return
	_enter(State.ORDERED)
	target = destination


func tick(delta: float) -> void:
	if dead:
		return
	hunger += delta
	if hunger >= _cfg.starve_seconds:
		dead = true
		starved.emit()
		return
	if not adult:
		age += delta
		if age >= _cfg.maturity_seconds:
			adult = true
			matured.emit()
	if state == State.EATING or state == State.FERTILIZING or state == State.IDLE:
		_timer -= delta
		if _timer <= 0.0:
			_finish_timed_state()


## Sensor: the ordered fish stopped against an algae.
func blocked_by_algae(algae: Object) -> void:
	if state != State.ORDERED:
		return
	_enter(State.EATING)
	food = algae
	_timer = _cfg.eat_seconds


## Sensor: the ordered fish stopped against a coral or a wall.
func blocked_by_other() -> void:
	if state != State.ORDERED:
		return
	_go_idle()


## Sensor: the ordered fish reached its destination. `empty_nest` is the empty
## nest under it, or null.
func arrived(empty_nest: Object) -> void:
	if state != State.ORDERED:
		return
	if empty_nest != null and adult:
		_enter(State.FERTILIZING)
		nest = empty_nest
		_timer = _cfg.fertilize_seconds
	else:
		_go_idle()


## Sensor: the algae being eaten disappeared (eaten by another fish, cyclone...).
func food_lost() -> void:
	if state == State.EATING:
		_enter(State.WANDER)


## Sensor: the nest being fertilized disappeared or is no longer empty.
func nest_lost() -> void:
	if state == State.FERTILIZING:
		_enter(State.WANDER)


func _finish_timed_state() -> void:
	match state:
		State.EATING:
			var eaten_algae := food
			hunger = 0.0
			_enter(State.WANDER)
			eat_finished.emit(eaten_algae)
		State.FERTILIZING:
			var fertilized_nest := nest
			_enter(State.WANDER)
			fertilize_finished.emit(fertilized_nest)
		State.IDLE:
			_enter(State.WANDER)


func _go_idle() -> void:
	_enter(State.IDLE)
	_timer = _cfg.idle_after_order_seconds


func _enter(new_state: State) -> void:
	state = new_state
	food = null
	nest = null
	_timer = 0.0
```

> Note on the tests: GDScript lambdas cannot reassign captured local variables, but they **can** assign member variables of the test instance (`starved_count += 1` inside the lambda refers to the member) and append to member arrays. That is why counters and arrays are members.

```gdscript
class_name FishVisual
extends Node2D
## Placeholder fish drawing in screen space (until real art lands):
## projected body ellipse, selection ring, hunger bar.

const BODY_COLOR := Color(0.3, 0.7, 1.0)
const RING_COLOR := Color(1.0, 1.0, 1.0, 0.9)
const BAR_BACK := Color(0.0, 0.0, 0.0, 0.6)
const BAR_FILL := Color(0.95, 0.3, 0.2)
const BAR_SIZE := Vector2(24.0, 4.0)
const JUVENILE_SCALE := 0.6
const RING_GAP := 4.0
const SEGMENTS := 16

var radius_world := 10.0
var hunger_threshold := 0.5
var adult := true:
	set(value):
		adult = value
		queue_redraw()
var selected := false:
	set(value):
		selected = value
		queue_redraw()
var hunger_ratio := 0.0:
	set(value):
		if not is_equal_approx(value, hunger_ratio):
			hunger_ratio = value
			queue_redraw()


func _draw() -> void:
	var radius := radius_world * (1.0 if adult else JUVENILE_SCALE)
	var body := _ellipse(radius)
	if selected:
		var ring := _ellipse(radius + RING_GAP)
		ring.append(ring[0])
		draw_polyline(ring, RING_COLOR, 2.0)
	draw_colored_polygon(body, BODY_COLOR)
	if hunger_ratio > hunger_threshold:
		var top := 0.0
		for point in body:
			top = minf(top, point.y)
		var back := Rect2(Vector2(-BAR_SIZE.x * 0.5, top - 8.0), BAR_SIZE)
		draw_rect(back, BAR_BACK)
		draw_rect(Rect2(back.position, Vector2(BAR_SIZE.x * hunger_ratio, BAR_SIZE.y)), BAR_FILL)


## A world-space circle of `radius` around the fish, projected to screen space.
func _ellipse(radius: float) -> PackedVector2Array:
	var points := PackedVector2Array()
	for i in SEGMENTS:
		points.append(Vector2.from_angle(TAU * i / SEGMENTS) * radius)
	return Game.projection.project_polygon(points, Vector2.ZERO)
```

```gdscript
class_name Fish
extends CharacterBody2D
## Fish (GDD §5.4): wanders, obeys orders, eats algae, fertilizes nests, starves.
## Rules live in FishBrain; this node moves, senses and draws.
## CONTRACT (used by Dev A nest, Dev B threats): setup(), is_adult(), destroy(),
## signal destroyed. Added for the commander: order(), selected.

signal destroyed

## Distance (world units) at which an order destination counts as reached.
const ARRIVE_DISTANCE := 2.0

var adult := true
var brain: FishBrain
var selected := false:
	set(value):
		selected = value
		if _visual != null:
			_visual.selected = value

var _wander: WanderSteering
var _visual: FishVisual


func setup(world_position: Vector2, p_adult: bool) -> void:
	position = world_position
	adult = p_adult


func _ready() -> void:
	collision_layer = Layers.FISH
	collision_mask = Layers.WALL | Layers.CORAL | Layers.ALGAE
	motion_mode = CharacterBody2D.MOTION_MODE_FLOATING
	add_to_group(Groups.FISH)
	var circle := CircleShape2D.new()
	circle.radius = Game.actors.fish_radius
	var shape := CollisionShape2D.new()
	shape.shape = circle
	add_child(shape)

	brain = FishBrain.new(Game.actors, adult)
	brain.starved.connect(destroy)
	brain.matured.connect(_on_matured)
	brain.eat_finished.connect(_on_eat_finished)
	brain.fertilize_finished.connect(_on_fertilize_finished)

	var rng := RandomNumberGenerator.new()
	rng.randomize()
	_wander = WanderSteering.new(rng, Game.actors.fish_wander_min_seconds, Game.actors.fish_wander_max_seconds)

	_visual = FishVisual.new()
	_visual.radius_world = Game.actors.fish_radius
	_visual.hunger_threshold = Game.actors.hunger_bar_threshold
	_visual.adult = adult
	ViewFollower.attach(self, _visual)


func _physics_process(delta: float) -> void:
	brain.tick(delta)
	if brain.dead:
		return
	_check_targets_still_exist()
	match brain.state:
		FishBrain.State.WANDER:
			_move(_wander.tick(delta), _speed() * delta)
		FishBrain.State.ORDERED:
			var to_target := brain.target - global_position
			if to_target.length() <= ARRIVE_DISTANCE:
				brain.arrived(_empty_nest_under())
			else:
				_move(to_target.normalized(), minf(_speed() * delta, to_target.length()))
	_visual.hunger_ratio = brain.hunger_ratio()


func is_adult() -> bool:
	return brain.is_adult() if brain != null else adult


## Player order (from FishCommander): swim straight to `destination` (world units).
func order(destination: Vector2) -> void:
	brain.order(destination)


func destroy() -> void:
	if is_queued_for_deletion():
		return
	selected = false
	remove_from_group(Groups.FISH)
	destroyed.emit()
	queue_free()


## Speed slows down with temperature (GDD §6, contract #1).
func _speed() -> float:
	return Game.actors.fish_speed * Game.by_temperature(1.0, Game.actors.fish_speed_hot_factor)


func _move(direction: Vector2, distance: float) -> void:
	var collision := move_and_collide(direction * distance)
	if collision == null:
		return
	var collider := collision.get_collider()
	if brain.state == FishBrain.State.ORDERED:
		if collider is Node and (collider as Node).is_in_group(Groups.ALGAE):
			brain.blocked_by_algae(collider)
		else:
			brain.blocked_by_other()
	else:
		_wander.on_blocked(collision.get_normal())


## Contract #4: the empty nest under the fish, or null.
func _empty_nest_under() -> Nest:
	var query := PhysicsPointQueryParameters2D.new()
	query.position = global_position
	query.collision_mask = Layers.NEST
	query.collide_with_areas = true
	query.collide_with_bodies = false
	for hit in get_world_2d().direct_space_state.intersect_point(query, 4):
		var nest := hit["collider"] as Nest
		if nest != null and nest.is_empty():
			return nest
	return null


func _check_targets_still_exist() -> void:
	if brain.state == FishBrain.State.EATING and not _alive_in(brain.food, Groups.ALGAE):
		brain.food_lost()
	elif brain.state == FishBrain.State.FERTILIZING:
		if not _alive_in(brain.nest, Groups.NESTS) or not (brain.nest as Nest).is_empty():
			brain.nest_lost()


func _on_matured() -> void:
	adult = true
	_visual.adult = true


## Contract #7: the eaten algae disappears.
func _on_eat_finished(algae: Object) -> void:
	if _alive_in(algae, Groups.ALGAE):
		(algae as Algae).destroy()


## Contract #4: the nest receives the eggs if it is still there and empty.
func _on_fertilize_finished(nest: Object) -> void:
	if _alive_in(nest, Groups.NESTS) and (nest as Nest).is_empty():
		(nest as Nest).fertilize()


## True if `entity` still exists and still belongs to `group` (destroy() leaves
## the group immediately, even when the node is freed later).
static func _alive_in(entity: Object, group: StringName) -> bool:
	return is_instance_valid(entity) and (entity as Node).is_in_group(group)
```

> Why `_check_targets_still_exist()` runs every frame: the eaten algae can be destroyed by another fish or a cyclone during the 3 s, and the nest can be destroyed or already fertilized. The brain then drops the target instead of feeding/fertilizing on a ghost.

```gdscript
class_name FishCommander
extends Node
## Player control of fish (GDD §5.4): click a fish to select it, click again to
## send it straight there. Right click / Esc deselects. Ignored while placing
## (contract #8).

var selected: Fish = null


## Index of the point nearest to `click` within `radius`, or -1.
static func pick_nearest(points: PackedVector2Array, click: Vector2, radius: float) -> int:
	var best := -1
	var best_distance := radius
	for i in points.size():
		var distance := points[i].distance_to(click)
		if distance <= best_distance:
			best = i
			best_distance = distance
	return best


func _unhandled_input(event: InputEvent) -> void:
	if Game.placing:
		return
	if event.is_action_pressed(InputActions.COMMAND):
		_on_command(Game.mouse_world())
		get_viewport().set_input_as_handled()
	elif event.is_action_pressed(InputActions.CANCEL) and is_instance_valid(selected):
		_select(null)
		get_viewport().set_input_as_handled()


func _on_command(click: Vector2) -> void:
	var fish := _fish_at(click)
	if fish != null:
		_select(fish)
	elif is_instance_valid(selected):
		selected.order(click.clamp(Vector2.ZERO, Game.grid.world_size()))
		_select(null)


func _fish_at(click: Vector2) -> Fish:
	var fishes := get_tree().get_nodes_in_group(Groups.FISH)
	var points := PackedVector2Array()
	for fish in fishes:
		points.append((fish as Node2D).global_position)
	var index := pick_nearest(points, click, Game.actors.fish_click_radius)
	return null if index < 0 else fishes[index] as Fish


func _select(fish: Fish) -> void:
	if is_instance_valid(selected):
		selected.selected = false
	selected = fish
	if fish != null:
		fish.selected = true
```
